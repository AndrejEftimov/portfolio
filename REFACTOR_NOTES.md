# Final architecture refactor notes

This checkpoint addresses the full pre-deployment review findings:

- project detail pages no longer create nested `<main>` landmarks;
- homepage section navigation is React-Router/base-path aware;
- GitHub Pages base-path logic supports repository Pages and an explicit custom-domain override;
- public role terminology is standardized to **Software Engineer**;
- MyCircle uses **Deployed** rather than **Live** when no public live URL is exposed;
- project images now carry intrinsic width/height metadata and validation;
- scroll memory persists per route in `sessionStorage` for the browser tab;
- deployment explicitly requires and validates the real committed `package-lock.json` before `npm ci`.

Important: keep the `package-lock.json` generated by the user's local `npm install`. It is intentionally not regenerated in this environment because registry access is unavailable; fabricating a lockfile would be incorrect.
